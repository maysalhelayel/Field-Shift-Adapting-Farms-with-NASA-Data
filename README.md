#دورة — مستكشف الدورات الزراعية

«دورة» تطبيق باللغة العربية، طُوّر باستخدام Python وStreamlit، ويدعم عرض المحتوى من اليمين إلى اليسار. يعتمد على بيانات NASA POWER المرفقة بالمشروع، ويعيد إجراء الحسابات انطلاقًا من ملفات JSON الأصلية.

يتيح التطبيق تعديل الموقع والفترة الزمنية ومحصول الأساس ومواعيد الزراعة والحصاد، إلى جانب تحديد الأولويات والقيود الزراعية. وبناءً على هذه المدخلات، يقارن بين ثلاث دورات زراعية تمتد كل منها على ثلاث سنوات، مع توضيح أسباب النتائج ومصادر البيانات والافتراضات المستخدمة، وإتاحة تنزيل الجداول والتقارير.

الحالة الافتراضية مخصّصة لتوضيح طريقة عمل التطبيق، ولا تصف مزرعة فعلية. فالبيانات المناخية مأخوذة من مصدر حقيقي، بينما تكرار زراعة القمح، والاعتماد على الزراعة البعلية، ومواعيد المحاصيل، كلها افتراضات معلنة. ولا يتضمن المشروع قياسات فعلية للتربة أو تنبؤات بالإنتاجية والدخل، كما لا يدّعي إثبات توفير المياه.

## التشغيل على الجهاز

يتطلب المشروع Python بإصدار من 3.11 إلى 3.13، ويُوصى باستخدام الإصدار 3.12. بعد فك ضغط الملفات، افتح الطرفية داخل مجلد المشروع ونفّذ الأوامر التالية:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

في Windows PowerShell، استبدل أمر تفعيل البيئة بالأمر التالي:

```powershell
.venv\Scripts\Activate.ps1
```

ويمكن تشغيل المشروع مباشرةً دون تفعيل البيئة:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

بعد التشغيل، افتح الرابط:

http://localhost:8501

تعمل بيانات العينة والحسابات والرسوم والتقرير دون اتصال بالإنترنت بعد تثبيت الحزم المطلوبة. أما خرائط الأساس وخط Google فيحتاجان إلى اتصال، ويُستخدم خط Arial بديلًا عند تعذّر تحميل الخط.

لا يتطلب جلب بيانات NASA POWER مفتاحًا خاصًا. ولتغيير موقع العينة، يجب استخدام وضع الجلب المباشر. وإذا فشل الجلب، يعرض التطبيق الخطأ ولا يستبدل البيانات ببيانات اصطناعية.

## إعادة إجراء التحليل والاختبارات

لإعادة إنتاج النتائج من البيانات الخام وتشغيل الاختبارات، استخدم:

```bash
python -m crop_rotation.pipeline --output outputs/rebuilt
python -m pytest -q
```

ينتج عن التحليل ملفات CSV للبيانات اليومية والشهرية والفصلية والسنوية، إضافةً إلى جداول الجودة والأحداث المناخية والفترات الجافة وحساسية عتبات المطر والاتجاهات والتقويم الزراعي والتعرض التاريخي ومقارنة الدورات وحساسية الأوزان.

وتشمل المخرجات أيضًا ملف الافتراضات `assumptions.json`، وتقريرًا عربيًا باسم `report.html`، وحزمة نتائج باسم `results.zip`. يمكن فتح التقرير في المتصفح مباشرةً، دون الحاجة إلى خادم أو اتصال بالإنترنت.

لإعادة جلب بيانات الفترة المحددة من المصدر، نفّذ:

```bash
python -m crop_rotation.pipeline --live --output outputs/live
```

تُحفظ الاستجابات الخام الجديدة في مجلد `data/cache`، مع بصمة لمعاملات الطلب ووقت الجلب ورابطه. ويتضمن الجلب مهلة انتظار ومحاولات إعادة عند التعثر. وقد تختلف البيانات المسترجعة حديثًا عن النسخة المرفقة إذا حدّث المصدر بياناته.

يُستخدم ملف `config.json` لضبط حالة التحليل، بينما يحتوي `crops.json` على قاعدة بيانات المحاصيل. يجب عدم حفظ أي كلمات مرور أو معلومات سرية في هذين الملفين.

## استخدام الواجهة

يمكن من الشريط الجانبي إدخال الإحداثيات أو رفع ملف GeoJSON يحتوي على معلم جغرافي واحد، ثم تحديد الفترة الزمنية ومحصول الأساس ومواعيد الزراعة والحصاد بصيغة `MM-DD`. كما يمكن إدخال معلومات الري والتربة، وتحديد المحاصيل المتاحة وفقًا للمعدات والسوق، وتعديل الأوزان والعتبات المستخدمة في المقارنة.

عند إدخال مضلع، يختار التطبيق نقطة صالحة داخله لتمثيله؛ لذلك لا تمثل البيانات متوسط المساحة كلها. ويوضح التطبيق أن الخلية المناخية قد تكون أكبر من مساحة الحقل، وما يترتب على ذلك من حدود في تفسير النتائج.

تتوزع الواجهة على الأقسام التالية:

- **المناخ:** يعرض المطر ودرجة الحرارة والبخر والنتح المرجعي ET₀، والفرق بين المطر وET₀، والشذوذ المناخي والأحداث والحساسية والاتجاهات.
- **مقارنة الدورات:** يعرض درجات البدائل ومساهمة كل معيار، مع بيان كفاية الأدلة والتحذيرات وقواعد الاستبعاد. وإذا اختار المستخدم الدخل وحده معيارًا للمقارنة، فلا يُنتج التطبيق ترتيبًا لغياب بيانات تدعم ذلك.
- **التقويم الزراعي:** يعرض ثلاثة مواسم، ويحسب تعرضها للظروف المناخية اعتمادًا على نوافذ تاريخية مماثلة. وهذه النتائج ليست توقعات للأعوام المعروضة.
- **الجودة والمصادر:** يوضح تغطية البيانات والافتراضات والمعادلات والوحدات الأصلية.
- **التقارير والتنزيل:** يتيح تنزيل التقرير بصيغة HTML، والجداول بصيغة CSV، وحزمة النتائج بصيغة ZIP.

## تنظيم ملفات المشروع

حُفظت البيانات الأصلية المرفقة في `data/raw/` دون تعديل، ويوثّق ملفا الطلب مصدرها. كما احتُفظ بملفات `data/processed/` والمخرجات السابقة للمراجعة، لكن التطبيق لا يعتمد على الحسابات القديمة، بل يعيد حساب النتائج من البيانات الخام.

تتوزع مهام الملفات الأساسية كما يلي:

- `crop_rotation/data.py`: قراءة المدخلات، ومعالجة GeoJSON، وجلب بيانات POWER وتخزينها مؤقتًا، وفحص الجودة والوحدات.
- `crop_rotation/climate.py`: حساب ET₀ والمؤشرات المناخية وتجميع البيانات.
- `crop_rotation/rotation.py`: تطبيق قواعد المقارنة وإعداد التقويم الزراعي والمفاضلة بين الدورات.
- `crop_rotation/pipeline.py`: تشغيل التحليل وإعداد التقرير وتصدير النتائج.
- `app.py`: عرض واجهة المستخدم واستدعاء وحدات التحليل نفسها المستخدمة في الاختبارات والدفتر التعليمي.
- `docs/`: توثيق المصادر وقاموس البيانات والمنهجية والتحقق والتقدم وعرض الهاكاثون.
- `notebooks/walkthrough.ipynb`: مثال تعليمي يستدعي الدالة `run`، دون إعادة كتابة الحسابات بطريقة مختلفة.

## حدود النتائج وما يحتاج إلى استكمال

تقدم المقارنة وسيلة استكشافية قائمة على قواعد واضحة، لكنها لا تمثل تحققًا زراعيًا ميدانيًا. ولتقييم الدورات بصورة أدق، يلزم توفير بيانات محلية عن الأصناف ومراحل نموها، والمياه المتاحة، وخصائص التربة، والمخلفات والآفات، والمعدات والأسعار.

مدة بقاء المحصول في الأرض لا تُعد قياسًا مباشرًا للغطاء الأرضي أو فقد التربة. كذلك، فإن انخفاض ET₀ أو عدد أيام الحر لا يثبت وحده انخفاض احتياج المحصول إلى المياه. ولا يمكن حساب البخر والنتح الخاص بالمحصول ETc دون معامل محصول Kc مناسب، أو إعداد ميزانية مائية للتربة دون مدخلاتها اللازمة.

تُستخدم معلومات الري المسجلة لتوضيح سياق الحالة، ولا تثبت توافر المياه فعليًا. لذلك لا يستطيع المحرك تأكيد ملاءمة الزراعة البعلية أو الحكم على جدوى حد رقمي معين للري.

لم تُنفّذ معالجة بيانات SMAP أو GPM أو NDVI أو ECOSTRESS أو SRTM أو GRACE ضمن هذا الإصدار، ولا يعرض التطبيق نتائج مستمدة منها. كما لا يتضمن تعلمًا آليًا أو نموذجًا للإنتاجية في غياب بيانات هدف مناسبة.

ولا تعادل فترة السنوات العشر خط أساس مناخيًا مدته ثلاثون عامًا، ولا تمثل توقعًا للمناخ مستقبلًا. أما ترتيب الدورات، فيعتمد على البدائل الحالية والأوزان والتقاويم المختارة؛ ولذلك فهو نتيجة مقارنة نسبية، وليس توصية ملزمة أو ضمانًا للنتائج.

يوضح ملف `docs/validation.md` ما اختُبر بالفعل وما لم يُختبر. وتُنسب البيانات المناخية إلى NASA POWER، مع إدراج المراجع الرسمية في `docs/sources.md`.
