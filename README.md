# دورة — مستكشف الدورات الزراعية

تطبيق Python/Streamlit عربي RTL يستعمل بيانات NASA POWER المرفقة، ويعيد الحسابات من JSON الخام. يتيح تغيير موقع وفترة وأولويات ومحصول أساس وتقويم وقيود، ويقارن ثلاث دورات عبر ثلاث سنوات مع أسباب ومصادر وافتراضات وتنزيلات.

**الحالة الافتراضية عرض، وليست وصفًا لمزرعة فعلية.** البيانات المناخية حقيقية، أما القمح المتكرر والري البعلي ومواعيد المحاصيل فافتراضات معلنة. لا تربة مقاسة ولا تنبؤ إنتاجية أو دخل أو ادعاء توفير مياه.

## التشغيل محليًا

يلزم Python 3.11–3.13، ويوصى 3.12. من مجلد المشروع بعد فك الضغط:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows PowerShell: استبدل سطر التفعيل بـ `.venv\Scripts\Activate.ps1`، أو نفذ `.venv\Scripts\python.exe -m pip install -r requirements.txt` ثم `.venv\Scripts\python.exe -m streamlit run app.py` مباشرة.

افتح http://localhost:8501 . تعمل العينة والحسابات والرسوم والتقرير دون اتصال بعد تثبيت الحزم؛ خرائط الأساس وخط Google يحتاجان اتصالًا، ويوجد خط Arial بديل. لا يلزم مفتاح NASA. تغيير نقطة العينة يحتاج وضع الجلب المباشر ولا يستبدل الفشل ببيانات اصطناعية.

## إعادة إنتاج النتائج والاختبارات

```bash
python -m crop_rotation.pipeline --output outputs/rebuilt
python -m pytest -q
```

تُنتج جداول CSV يومية/شهرية/فصلية/سنوية، جودة وأحداث وفترات جافة وحساسية المطر والاتجاهات والتقويم والتعرض التاريخي ومقارنة الدورات وحساسية الأوزان، assumptions.json، تقريرًا عربيًا report.html وحزمة results.zip. افتح التقرير بمتصفح؛ لا يتطلب خادمًا أو إنترنت.

إعادة جلب الفترة من المصدر: `python -m crop_rotation.pipeline --live --output outputs/live` . البيانات الخام الجديدة في data/cache مع بصمة معاملات الطلب ووقت ورابط الجلب؛ retries وtimeouts. قد يختلف رد حديث عن لقطة مرفقة بسبب تحديثات المصدر. config.json للحالة، crops.json لقاعدة المحاصيل. لا تضع أسرارًا فيها.

## الواجهة

- الشريط الجانبي: إحداثيات أو GeoJSON لمعلم واحد، تواريخ، محصول الأساس، الزراعة والحصاد بصيغة MM-DD، ري وتربة ومحاصيل متاحة للمعدات والسوق وأوزان وعتبات.
- المضلع يمثّل بنقطة داخلية صالحة، لا متوسط مساحة. الخلية المناخية أكبر من الحقل وتظهر الحدود صراحة.
- المناخ: المطر والحرارة وET₀ وP−ET₀ والشذوذ والأحداث والحساسية والاتجاهات.
- المقارنة: الدرجات ومساهمات المعايير وكفاية الأدلة وتحذيرات وقواعد الاستبعاد. عند اختيار الدخل فقط لا ترتيب، لغياب أدلة دخل.
- التقويم: ثلاثة مواسم مع تعرض من النوافذ التاريخية؛ ليس توقعًا للأعوام المعروضة.
- الجودة والمصادر: التغطية والافتراضات والمعادلات والوحدات الأصلية؛ التقارير والتنزيل: HTML/ZIP/CSV.

## البنية وتتبع العمل السابق

- `data/raw/` الأصل المرفق محفوظ دون تعديل، وملفا request يسجلان مصدره. `data/processed/` وملفات outputs القديمة محفوظة للمراجعة؛ لا يعتمد التطبيق على حساباتها.
- `crop_rotation/data.py`: المدخلات وGeoJSON وPOWER/cache والجودة والوحدات.
- `climate.py`: ET₀ والمؤشرات والتجميع؛ `rotation.py`: القواعد والتقويم والمفاضلة؛ `pipeline.py`: التحليل والتقرير/التصدير.
- `app.py`: الواجهة فقط وتستدعي الوحدات نفسها التي تختبر وتستخدم بالـNotebook.
- `docs/`: المصادر وقاموس البيانات والمنهج والتحقق والتقدم وعرض الهاكاثون.
- `notebooks/walkthrough.ipynb`: مثال تعليمي يعيد استعمال run دون حسابات مختلفة.

## حدود متبقية

المقارنة استكشافية بقواعد شفافة ولا تمثل تحققًا زراعيًا. تاريخ نمو كل صنف وتوافر المياه والتربة والمخلفات والآفات والمعدات والأسعار يحتاج بيانات محلية. مدة إشغال الأرض ليست قياس غطاء أو فقد تربة. انخفاض ET₀/أيام الحر ليس انخفاضًا مثبتًا في طلب المحصول. لا ETc بلا Kc مناسب، ولا ميزانية تربة بلا مدخلاتها. الري المسجل سياق وليس دليل توافر ماء؛ لا يستطيع المحرك إثبات الملاءمة البعلية أو جدوى حد ري رقمي.

SMAP/GPM/NDVI/ECOSTRESS/SRTM/GRACE لم تنفذ، ولا تعرض نتائج منها. لا تعلم آلي أو نموذج إنتاجية بلا بيانات هدف. العشر سنوات ليست خط أساس 30 سنة أو توقعًا مناخيًا. الترتيب نسبي للبدائل الحالية والأوزان والتقاويم، وليس توصية إلزامية أو ضمانًا.

تفاصيل ما اختُبر فعلًا وما لم يختبر في docs/validation.md. بيانات POWER تُنسب إلى NASA POWER؛ المراجع الرسمية في docs/sources.md.
